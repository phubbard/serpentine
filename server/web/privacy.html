Serpentine — Privacy

Last updated: 2026-09-19.

Serpentine plans motorcycle rides. To do that it sends your starting point to Serpentine's own server, which plans the route and forgets it. No accounts. No analytics. No ads. No tracking.

What the app sends, and to whom

  • Your ride request, to Serpentine's server. When you tap Plan, the app sends the start point (your location or a place you searched for), the kind of ride, distance, twistiness, direction and, if you turned on charging, your starting battery level, over HTTPS to serpentine.phfactor.net. That server is run by Paul Hubbard, an individual developer, on his own hardware. There is no account and nothing that identifies you or your device in the request.
  • What the server keeps. The planned ride (including its start point and route) stays in the server's memory for up to 24 hours so that "Share GPX" and repeat requests work, then it is discarded. It is never written to disk, never logged and never shared, except as below.
  • Charging stops, via NREL. Only if you turn on charging: to find chargers along the ride, Serpentine's server sends the shape of the route (a line on the map, with nothing about you or your device) to the U.S. Department of Energy's Alternative Fuel Stations API (developer.nlr.gov, formerly NREL). Your phone never contacts it directly.
  • Maps, place search and navigation, via Apple. The map, the place search and turn-by-turn guidance are Apple Maps. Search terms go to Apple, not to Serpentine, and when you tap "Navigate in Apple Maps" the planned stops are handed to the Maps app. Apple's privacy policy covers those.

Serpentine contacts no other services. It contains no third-party code, SDKs, analytics or crash reporting beyond Apple's own.

Location

Serpentine asks for location "While Using the App" and reads it only when you tap Use my location, once, to set the start of the ride. It never tracks you in the background. You can revoke it at any time in Settings → Privacy & Security → Location Services → Serpentine, and plan from a searched place instead.

Server logs

The web server in front of Serpentine keeps an access log to spot abuse: the time, the kind of request (for example /v1/plan), whether it worked and how long it took, and a truncated IP address (only the first half of an IPv4 address). It does not record locations, routes, request contents or browser details. Log entries are deleted after 30 days. Serpentine's own server log records only the kind of ride and summary numbers such as its length and how long planning took.

On your phone

Your plan settings stay in the app. When you share a GPX file, the app saves it to its own temporary storage so the share sheet can send it where you choose. Nothing is uploaded anywhere else.

The web test page

serpentine.phfactor.net/v1/ is a test page for the same planner. It loads nothing from other websites: its map images are fetched by Serpentine's server from OpenStreetMap and cached there, so OpenStreetMap never sees you. Map data © OpenStreetMap contributors.

Children

Serpentine is a route planner for licensed motorcycle riders and is not directed at children.
